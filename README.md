# もう二度と 村探索モック
共同確認用・陽菜v149統合版（2026年10月26日）。
https://dolphin0224-game.github.io/mou-nidoto-village-mock/

陽菜の更新モデルを、冒頭の夢・バス内のカットシーンとゲーム中の同行キャラクターへ統合。
カットシーンでは表情・視線・演技を旧Timelineから受け継ぎ、座り姿勢と衣服を補正。ゲームではHumanoid歩行・会話アニメーションを使用。
PCの新しいChrome/Edgeを使用。初回ダウンロードは約900MB。ログイン不要です。
WASD移動、マウスドラッグで視点、E調べる、M地図、Pスマホ、Enter/Space会話。
本編は到着から宿の同行者選択と通知まで。別の「村の自由探索 · 確認用」で13エリアを確認できます。
台詞・観察の○○は未執筆箇所の意図です。事件・救出・全建物の室内・最終演技は未完成です。
ゲーム本体のソース、編集可能なモデル、未公開の筋書きは含みません。
